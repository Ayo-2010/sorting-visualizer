# Sorting Visualiser

A bar chart that sorts itself, one comparison at a time.

## Features

- Bubble, selection, insertion and quick sort
- Adjustable array size from 10 to 60 bars
- Speed control from slow to near instant
- Colour states for comparing, swapping and sorted bars
- Live comparison and swap counters
- Shuffle to generate a new random array

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    algorithms and animation
```

## Tech

Plain HTML, CSS and JavaScript.
